# 기능명세서

`Docs/USECASE.md`의 유스케이스(UC01~UC28)를 기능 단위로 상세화한 문서다. 기능ID(FS-xx)는 UC 번호와 1:1로 대응한다.

## 1. 회원/프로필

| 기능ID | 기능명 | 관련 유스케이스 | 설명 | 주요 흐름 | 예외/제약사항 |
| --- | --- | --- | --- | --- | --- |
| FS-01 | 회원가입 | UC01 | 이메일/비밀번호 등으로 신규 계정 생성 | 이메일·비밀번호 입력 → 중복확인·유효성 검사 → 계정 생성 | 이메일 중복 시 가입 불가 |
| FS-02 | 로그인 | UC02 | 등록된 계정으로 인증 | 이메일·비밀번호 입력 → 인증 → 세션/토큰 발급 | 인증 실패 시 오류 안내 |
| FS-03 | 개인정보 관리 | UC03 | 나이, 거주지 등 개인정보 등록·수정 | 개인정보 입력/수정 → 저장 → 프로필 반영 | - |
| FS-04 | 사업자 정보 관리 | UC04 | 업종, 사업자 유형, 사업자등록일, 창업일 등 등록·수정 | 사업자 정보 입력/수정 → 저장 → 세액감면 판정·정책 추천에 반영 | 이 정보가 없으면 세액감면 판정(FS-13)·정책 추천(FS-19) 이용 불가 |

## 2. AI 상담(챗봇)

| 기능ID | 기능명 | 관련 유스케이스 | 설명 | 주요 흐름 | 예외/제약사항 |
| --- | --- | --- | --- | --- | --- |
| FS-05 | AI 챗봇 이용 | UC05 | 자연어 질문에 대해 AI가 응답 | 질문 입력 → 의도 분류 → RAG 기반 응답 생성 → 응답 표시 | 근거 문서 검색 결과가 없으면 "확인 필요" 안내로 대체(환각 방지) |
| FS-06 | 세금/경비처리/절세 Q&A | UC06 | 세법·경비·절세 관련 질의응답 | 질문 입력 → 세법 자료 기반 RAG 검색 → 답변 생성(FS-08 근거 포함) | 세무사·법률 자문을 대체하지 않음을 답변에 고지 |
| FS-07 | 정책 Q&A | UC07 | 지원정책 관련 질의응답 | 질문 입력 → 정책 문서 기반 RAG 검색 → 답변 생성 | - |
| FS-08 | 답변 근거 확인 | UC08 | AI 답변에 사용된 근거 문서·출처 확인 | 답변 선택 → 근거 문서 목록·원문 위치 조회 → 표시 | 근거 문서가 없는 답변은 "일반 지식 기반"으로 표기 |

## 3. 세무 관리

| 기능ID | 기능명 | 관련 유스케이스 | 설명 | 주요 흐름 | 예외/제약사항 |
| --- | --- | --- | --- | --- | --- |
| FS-09 | 사업자 유형 진단 | UC09 | 사용자 조건 기반 사업자등록 유형 안내 | 사업 조건 입력 → 유형별 조건 비교 → 추천 유형·비교표 제공 | 법적 확정 판단이 아닌 참고용 안내 |
| FS-10 | 세금 정보 관리 | UC10 | 사용자별 세무 관련 정보 등록·조회 | 세무 정보 입력 → 저장 → 캘린더·리마인더에 반영 | - |
| FS-11 | 통합 일정 캘린더 조회 | UC11 | 사업자 유형 기준 세금 신고·납부 일정과, 사용자의 저장/추천 지원정책의 신청기한을 통합해 홈 화면 캘린더에 표시 | 사용자 조건 조회 → 해당 세목 일정 필터링 + 저장(FS-23)·추천(FS-19) 정책의 신청기한 조회 → 이벤트 통합 → 홈 화면 캘린더 렌더링 | 정책 일정은 사용자가 저장했거나 추천된 정책 기준으로만 노출 |
| FS-12 | 맞춤 리마인더 설정 | UC12 | 세금 또는 지원금 일정 알림 등록·관리 | 알림 대상 일정(세금/지원금) 선택 → 알림 시점 설정 → 등록 | 알림 발송 채널(이메일/푸시 등)은 TBD |
| FS-13 | 청년창업 세액감면 자동판정 | UC13 | 나이·지역·업종·창업 시점 조건으로 세액감면 대상 여부 판정 | 사업자·개인 정보 조회 → Rule 기반 요건 판정 → 판정 결과 + 법령 근거(FS-08) 제공 | 최종 법적 판단이 아니며 세무 전문가 확인 권고 문구 포함 |

| 기능ID | 기능명 | 관련 유스케이스 | 설명 | 주요 흐름 | 예외/제약사항 |
